# 教育部注音筆順資料標示

本目錄的 37 個注音符號 SVG，由 Kid Learning 專案依據中華民國教育部
《國語注音符號手冊》數位版所提供的注音符號動畫 XML／SVG 資料轉製，
用於離線筆順引導與筆畫中線比對。

- 原始資料提供者：中華民國教育部
- 原始資料頁：https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html
- 授權：Creative Commons Attribution 4.0 International（CC BY 4.0）
- 修改內容：拆分為 37 個獨立 SVG、統一 viewBox、加入中線引導樣式，
  將中線座標正規化為 App 的 0～1 手寫比對資料，並依使用者提供的
  描寫練習範例採用 `ㄖ` 的三筆替代寫法（左直連下橫、上橫連右直、
  內斜線）。

教育部另說明，完整數位手冊採 CC BY-ND 3.0；本專案只使用該頁明確
列為可獨立下載、採 CC BY 4.0 的注音符號動畫 XML／SVG 資料。
